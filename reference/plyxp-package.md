# plyxp: Data masks for SummarizedExperiment enabling dplyr-like manipulation

The package provides \`rlang\` data masks for the SummarizedExperiment
class. The enables the evaluation of unquoted expression in different
contexts of the SummarizedExperiment object with optional access to
other contexts. The goal for \`plyxp\` is for evaluation to feel like a
data.frame object without ever needing to unwind to a rectangular
data.frame.

## Value

API for using S4 classes with rlang data masks
